# Sales Forecast Prediction Project

This project predicts future business sales using Machine Learning.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Steps Performed
1. Created sales dataset
2. Visualized sales graph
3. Trained Linear Regression model
4. Predicted next month sales
5. Displayed forecast graph

## Output
Predicted Next Month Sales ≈ 425
